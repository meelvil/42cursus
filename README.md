## 📖 About

[**42**](https://42.fr) is a peer-to-peer programming school: no teachers, no lectures. Students learn by building projects, reading documentation, and reviewing each other's code. The curriculum starts with C and the fundamentals of how computers actually work, then moves on to systems programming, algorithms, graphics, networking and beyond.

This repository gathers my work as I go through it. I've just started, so expect it to grow over time.

## 🛠️ Skills I'm building

- Low-level C programming and memory management (`malloc`, `free`, pointers)
- Writing clean code that follows the **Norm** (42's strict style guide)
- Building with `Makefile`s and static libraries
- Variadic functions (`stdarg`) and recursion
- Debugging with `valgrind` and `gdb`
- Peer evaluation and collaborative learning

## 🚀 Usage

Each project lives in its own folder and has its own `Makefile` and README.

```bash
git clone https://github.com/meelvl/42cursus.git
cd 42cursus/libft
make
```
