Les fonctions en paramètre

Comprendre ft_strmapi de A à Z — en jouant. Fais les mini-défis pour gagner de l'XP.
ÉTAPE 1

Une fonction, c'est une adresse

Quand ton programme est lancé, tout est en mémoire : tes variables, mais aussi le code de tes fonctions. Chaque fonction commence à une adresse précise. Et comme pour une variable, on peut stocker cette adresse dans un pointeur.

int x = 42;adresse : 0x7ffc10
contient la valeur 42
int *p = &x;adresse : 0x7ffc18
contient 0x7ffc10 (l'adresse de x)
char to_upper(…) { … }adresse : 0x4011a6
le code de la fonction vit ici
char (*f)(…) = to_upper;adresse : 0x7ffc20
contient 0x4011a6 → f pointe vers la fonction
Idée clé : passer une fonction en paramètre = passer son adresse. La fonction qui la reçoit pourra ensuite l'appeler quand elle veut. C'est comme donner à quelqu'un le numéro d'un traiteur : il décidera quand appeler.
ÉTAPE 2

Décoder la syntaxe (la partie qui fait peur)

Clique sur chaque morceau de la déclaration :

char (*f) (unsigned int, char)
👆 Clique sur un morceau.
Piège n°1 : les parenthèses autour de *f.
char (*f)(unsigned int, char) → f est un pointeur vers une fonction qui renvoie un char.
char *f(unsigned int, char) → f est une fonction qui renvoie un char *. Totalement différent !

Dans ton sujet :

char *ft_strmapi(char const *s, char (*f)(unsigned int, char));

Lis-le : « ft_strmapi prend une string s et f, une fonction qui prend (un index, un char) et renvoie un char. Elle renvoie un nouveau char *. »

ÉTAPE 3

Écrire la fonction à passer, et l'appeler

/* Ta fonction : DOIT avoir exactement la même signature que f */
char to_upper(unsigned int i, char c)
{
    (void)i;                    // i inutilisé ici (évite le warning)
    if (c >= 'a' && c <= 'z')
        return (c - 32);
    return (c);
}

char *res = ft_strmapi("salut", to_upper);   // ← PAS de parenthèses !
Piège n°2 : to_upper = l'adresse de la fonction (✅). to_upper(0, 'a') = on appelle la fonction et on passe son résultat (❌ ici).
Appeler via le pointeur : dans ft_strmapi, on écrit simplement f(i, s[i]). Le C sait que f est un pointeur de fonction et saute à l'adresse stockée. ((*f)(i, s[i]) marche aussi, c'est pareil.)

  ÉTAPE 5
  
Les pièges à éviter (ceux qui font échouer à la moulinette)

  
    
    
  • malloc(strlen(s) + 1) — oublier le +1, c'est écrire le '\0' hors de la mémoire allouée.
    • 
    
  • Terminer res avec '\0' après la boucle.
    • 
    
  • Si malloc échoue → return NULL (c'est écrit dans le sujet).
    • 
    
  • Protéger s et f NULL : appeler un pointeur de fonction NULL = segfault direct.
    • 
    
  • Index = unsigned int : f reçoit bien l'index avant le caractère.
    • 
    
  • Ne modifie pas s : elle est const, on construit une nouvelle string.
    • 
  

  
🧠 Pourquoi c'est utile ? Même boucle, comportement différent selon f. C'est l'idée derrière qsort, les callbacks, les listes (ft_lstmap, ft_lstiter au prochain exo)…
